# Beauty Plan

A React and TypeScript web app for a beauty planning experience. The app currently includes a home page, a services page, and a beauty plan page.

## Getting started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server. |
| `npm run build` | Run the TypeScript project build and create a production build. |
| `npm run preview` | Preview the production build locally. |
| `npm run lint` | Run ESLint across the project. |
